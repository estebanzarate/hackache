## System Info

```bash
uname -a
hostname
id
whoami
cat /etc/passwd
cat /etc/os-release
```

## Network

```bash
ip a
ss -tlnp
netstat -tlnp
cat /etc/hosts
```

## Processes

```bash
ps aux
ps -ef
```

## Interesting Files

```bash
find / -perm -4000 2>/dev/null
find / -writable 2>/dev/null | grep -v proc
cat /etc/crontab
crontab -l
```
